## Source Gate Before Lesson Authoring

Do not create official-looking Classroom Mathematics California units or lessons until all of the following are available and reviewed:

1. Grade 3 Volume 1 and Volume 2 tables of contents.
2. Exact edition, copyright, and identifying information.
3. School-provisioned student access and an inventory of enabled i-Ready components.
4. Moreland or teacher guidance for home use and classroom pacing.
5. Authorized lesson-level student materials sufficient to establish the exact sequence and page mappings.

Public product descriptions, state standards, and the old Eureka sequence are not substitutes for those sources.

## Reuse Boundary

Visually validated and reused:

- compact source ledger separating standards, framework guidance, and official i-Ready lesson design;
- visible framework evidence cards reproducing the exact Figure 6.53 connection structure and Figure 6.54 guidance without inventing a curriculum sequence;
- the model → explanation → expectation rhythm used to make mathematical structure visible;
- visual representations such as arrays, number lines, fraction models, area models, graphs, and varied shapes only where California explicitly requires, exemplifies, or recommends them;
- accessibility, hierarchy, spacing, and desktop layout patterns.

The first implementation of a second seven-link in-page navigation row was removed after live review. It duplicated the domain navigation, looked like broken routing when used, and compressed the 13-inch desktop layout without adding content value. Its fragment IDs, scroll offsets, and unused CSS were also removed. Every remaining tab changes the route and loads a distinct content page. Concept explanations use expandable source-backed rows instead of a permanently open card wall.

Visually reviewed and rejected for transfer:

- Eureka module and lesson order;
- Eureka topic tabs, module counts, lesson counts, assessment placement, lesson selector, next/previous navigation, and search behavior;
- Eureka objectives, problem sets, homework, answer keys, or page citations;
- assumptions that one shared standard creates a one-to-one lesson mapping;
- Baker or Moreland pacing not established by a current primary source.
